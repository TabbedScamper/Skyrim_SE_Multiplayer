## Exact-version address gate

The newer [alandtse/CommonLibSSE-NG](https://github.com/alandtse/CommonLibSSE-NG/tree/2dde70e8bdf9890bbd5e648966c7d2c24e83092f) pin handles Skyrim's 1.7 branch as AE and parses Address Library format 5. The older bundled CommonLib source is a poor authority for 1.7.104 layout decisions. The corrected read-only [manifest builder](../../Tools/EngineAtlas/Build-FunctionManifest.py) generated a private 15,600-label candidate map, with 16 ambiguous IDs and 1,508 unresolved symbols. Labels are mined from source, not proven by disassembly.

The [function-boundary inspector](../../Tools/EngineAtlas/Inspect-FunctionBoundary.py) checked the exact installed EXE: IDs `36544`, `77851` and `78382` coincide with `.pdata` function starts; `39484` (`AIProcess::GetHeadtrackTarget` candidate) and `62640` have no unwind entry. A missing entry is inconclusive for leaf functions/thunks. ID `39484` remains **unsafe to call**: an earlier call crashed at `SkyrimTogether.exe+0x6FF05A`, close to its mapped RVA `0x6FF050`. ID `36544` has conflicting source labels (`Main::Update` and `winMain`). Neither a map nor `.pdata` proves the receiver, signature, identity or hook phase.

## Independent review and next trial

Reviewer A and Reviewer B reviewed the fork independently, read-only. Both emphasized decision-state tracing before broad bone writes. Reviewer A flagged follower `ScriptSetStage` under `ScopedQuestOverride` as a possible fragment-authority leak; Reviewer B emphasized the existing scene timeline, animation graph and loading-screen probes but did not validate that causal claim. The next minimal experiment is a selected MQ101 stage/scene-action trace on **both** PCs at a common host source tick, while recording native dispatch, scene phase, package, clip activation and physics pre-step as distinct layers. Do not patch authority until the first divergent layer is measured.
